# Repository Overview

This repository contains a collection of Python scripts and utilities that demonstrate various programming concepts, including:

- Basic arithmetic operations (`add.py`, `divide.py`, `multiply.py`).
- Interactive and threaded agents (`interactive_agent.py`, `threaded_agents.py`, `modern_thread_execution.py`).
- Example scripts for generating pyramids (`pyramid1.py`, `pyramid2.py`).
- A terminal‑based agent (`terminal_agent.py`).
- Core configuration and entry point (`config.py`, `main.py`).

## Organization

- **`output/`** – All Python scripts generated by AI agents are stored here. This keeps the repository root clean and makes it easy to locate generated code.
- **`README.md`** – This file, providing an overview and usage instructions.
- **`prompt.txt`** – Contains the original prompt used for generating the scripts.

## Usage

1. **Running a script**: Navigate to the `output` directory and execute the desired script, e.g.:
   ```bash
   cd output
   python add.py
   ```

2. **Threaded execution**: The `threaded_agents.py` and `modern_thread_execution.py` scripts showcase how to run multiple agents in parallel using Python's threading facilities.

3. **Interactive agent**: Launch `interactive_agent.py` to interact with the AI‑driven terminal agent.

Feel free to explore, modify, and extend the scripts as needed.
